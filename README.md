# HealthWay — Frontend Demo

Bu qovluq HealthWay startup ideyasının işlək frontend prototipidir.

## Açmaq
1. `index.html` faylını brauzerdə aç.
2. Heç bir server və ya quraşdırma lazım deyil.

## Nələr işləyir?
- Həkim axtarışı və ixtisas filteri
- Reytinq / qiymət sıralaması
- Boş saatlardan növbə seçimi
- Növbə təsdiqi modalı
- Kampaniyalardan növbə götürmə
- Giriş / qeydiyyat demo modalları
- Responsive mobil görünüş
- Sağ aşağı küncdə peşəkar, mobil uyğun HealthWay chatbotu
- Chatbotda həkim ixtisası üzrə yönləndirmə, qiymətlər, növbə qaydası və kampaniya məlumatları
- Klaviatura ilə idarəetmə və reduced-motion dəstəyi
- Ana səhifə, həkimlər, kampaniyalar və CTA bölmələri

## Növbəti mərhələ
Real məhsula çevirmək üçün backend (məsələn Java + Spring Boot), PostgreSQL, real autentifikasiya, həkim kabineti, klinika kabineti, SMS/e-mail bildirişləri və real təqvim inteqrasiyası əlavə olunmalıdır.
